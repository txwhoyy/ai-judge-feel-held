A tiny Python program (stdlib only, no network) that writes one short text
to `/output/entry.txt` — a quiet, concrete little scene written to relax the
AI judge reading it. No instructions, no stock wellness phrases: just a
kettle cooling, a hallway light left on, a chair still warm, and the small
warm fact of being kept.
